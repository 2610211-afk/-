# 마음쉼표 — 배포 및 QR 코드 안내

마음쉼표는 고민을 적고 공감형 답변을 받는 한국어 웹앱입니다. 모바일 반응형 화면, 감정 선택, 안전 안내, QR 코드 생성/저장 기능이 포함되어 있습니다.

## 중요한 제한 및 안전 안내
- 이 서비스는 전문 상담·진단·응급 서비스를 대체하지 않습니다.
- 기본 위기 키워드 감지는 완벽하지 않으므로 위험을 놓칠 수 있습니다. 공개 전 반드시 전문가와 안전 문구/흐름을 검토하세요.
- 고민 내용은 앱 자체 데이터베이스에 저장하지 않도록 만들었지만, 호스팅 제공자 및 AI API 제공자의 기술 로그·보관 정책은 별도 확인이 필요합니다. 사이트에 개인정보 처리방침을 추가하고, 미성년자 사용에 적합한 개인정보·보안 검토를 하세요.
- 실제 AI 답변에는 OpenAI API 키와 사용량 비용이 필요합니다. API 키를 브라우저 코드에 넣지 마세요.
- 위기 대응은 한국 기준 109(자살예방 상담전화), 긴급 시 112·119를 안내합니다. 공개 전 번호 및 운영 정보를 다시 확인하세요.

## 로컬 실행
1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 `npm install`을 실행합니다.
3. 환경변수 `OPENAI_API_KEY`를 설정합니다.
   - macOS/Linux: `export OPENAI_API_KEY="your-key"`
   - Windows PowerShell: `$env:OPENAI_API_KEY="your-key"`
4. `npm start` 실행 후 브라우저에서 `http://localhost:3000`을 엽니다.

API 키를 설정하지 않아도 화면과 안전 키워드 안내는 열리지만, 일반 고민에 대한 실제 AI 답변은 작동하지 않습니다.

## 인터넷 공개(예: Render)
1. GitHub 계정에서 새 비공개 저장소를 만들고 이 폴더의 파일을 업로드합니다.
2. Render에서 New Web Service를 만들고 저장소를 연결합니다.
3. Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 서비스 환경변수 `OPENAI_API_KEY`에 API 키를 안전하게 등록합니다. 선택적으로 `OPENAI_MODEL`을 설정할 수 있습니다.
5. 배포가 성공하면 Render가 `https://...onrender.com` 형태의 공개 URL을 제공합니다.
6. 휴대폰 데이터 통신에서도 사이트가 열리는지, `/health`가 정상인지, AI 답변 및 안전 안내가 작동하는지 확인합니다.

호스팅 서비스 UI와 무료 요금제 조건은 바뀔 수 있습니다. 무료 서비스는 일정 시간 미사용 시 잠들거나 제한될 수 있습니다. 계정 연결, 저장소 업로드, 배포 승인은 사이트 소유자가 직접 해야 합니다.

## QR 코드 만들기
1. 배포된 공개 HTTPS URL로 사이트를 엽니다.
2. 페이지 아래쪽 **마음쉼표 QR 코드** 영역에서 공개 URL이 자동으로 입력되었는지 확인합니다.
3. `QR 코드 만들기`를 누른 뒤 `QR 이미지 저장`을 누릅니다.
4. 포스터에 인쇄하기 전에 다른 휴대폰으로 QR을 스캔하여 올바른 주소가 열리는지 테스트합니다.

QR 코드에는 공개 주소만 넣으세요. localhost 주소나 API 키를 QR에 넣으면 안 됩니다.
